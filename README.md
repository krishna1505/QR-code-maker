# QR Code Maker

A simple and responsive QR Code Generator built using **HTML, CSS, and JavaScript**. This application allows users to instantly generate QR codes for text, URLs, and other input data with a clean and user-friendly interface.

## 🚀 Features

* Generate QR codes instantly
* Simple and intuitive user interface
* Responsive design for mobile and desktop devices
* Lightweight and fast performance
* No installation required
* Real-time QR code generation

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* QR Code API

## 📂 Project Structure

```bash
QR-code-maker/
│
├── index.html      # Main application page
├── style.css       # Styling and layout
├── script.js       # QR code generation logic
└── README.md       # Project documentation
```

## 📸 Preview

Enter any text or URL and click the generate button to create a QR code instantly.

## ⚙️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/QR-code-maker.git
```

2. Navigate to the project folder:

```bash
cd QR-code-maker
```

3. Open `index.html` in your browser.
